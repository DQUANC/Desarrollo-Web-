# Clase 2 – Angular Basics

Practice project covering Angular template fundamentals: data binding, functions, objects, and arrays.

**Stack:** Angular 21 · TypeScript · Angular SSR (Express) · Vitest

---

## What it covers

| Section | Concepts demonstrated |
|---------|----------------------|
| 📌 Variables | Template interpolation of `nombre`, `apellido`, `titulo` |
| ➕ Operations | Inline arithmetic expressions in templates |
| ⚡ Functions | `DuplicarNumero`, `SumarNumeros`, `ConcatenarNombres` |
| 🎬 Object | Single `pelicula` object with title, release date, and price |
| 🎬 Array – Movies | `arregloPelicula` rendered with `@for` loop |
| 🎮 Array – Games | `arregloVideojuego` with images, dates, and prices |

---

## Running the project

```bash
npm install        # Install dependencies
npm start          # Dev server at http://localhost:4200
npm run build      # Production build → dist/
npm test           # Run tests with Vitest
```
