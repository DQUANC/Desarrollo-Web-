Bienvenido al sistema. Usa el menú de navegación para cambiar de página.

¿Cómo funcionan las rutas?

  • / → muestra este componente Home
  • /productos → muestra el componente Productos
  • /clientes → muestra el componente Clientes
  • /contactos → muestra el componente Contactos
  • cualquier otra ruta → redirige a / (wildcard **)

El componente <router-outlet> en app.html es el lugar donde Angular renderiza el componente correspondiente a la ruta activa.
